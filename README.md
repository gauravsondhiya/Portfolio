## ✨ Features

- **Editorial & Minimalist Design:** Clean typography paired with a warm terracotta (`#7B3F32`) accent palette.
- **Interactive GitHub Activity:** Live contribution graph powered by `react-github-calendar`.
- **Projects Showcase:** Detailed cards highlighting live demos, source code repositories, and tech stacks.
- **Responsive Layout:** Optimized for seamless viewing across desktop, tablet, and mobile devices.
- **Fast Deployment:** Continuously deployed via Netlify.

- **Frontend:** React, JavaScript (ES6+)

## 🚀 Getting Started

To run a local copy of this portfolio on your machine, follow these steps:

### Prerequisites

- Node.js (`v18+` recommended)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/gauravsondhiya/<your-repo-name>.git
   cd <your-repo-name>
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   *(Note: Use `npm start` if created with Create React App.)*

4. **Build for production:**
   ```bash
   npm run build
   ```
